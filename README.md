# LCD Sprite Drawer

Space Engineers 1のProgrammable Blockで、LCDへ図形・文字・時間アニメーション・ブロック値に連動した表示を描くスクリプトです。
**2.0.1 / Pre-release**。MIT Licenseで公開しています。

[公式配布先](https://github.com/SunokoHub/SpaceEngineers-InGameScript-Product-LCDSpriteDrawer-Release) の `dist/LCDSpriteDrawer-2.0.1.cs` がゲーム投入用本文です。
Releasesに配布されている場合も同名ファイルを使用できます。`src` は編集用ソースで、そのままPBへ貼るものではありません。
短縮生成しているため、コードを読む場合は [ソース解説](docs/SOURCE.md) と [ビルド手順](docs/BUILD.md) を参照してください。

## 導入

1. ワールドのスクリプト実行を許可し、PBにゲーム投入用本文を貼り付けてコンパイルします。更新の場合は先に旧本文で `stop` を実行し、CustomDataを控えてください。
2. 表示ブロックのCustomDataへ、独立行 `LCDSpriteDrawer` を追加します。または `[Tags]` の `LCDSpriteDrawer=true` で選択できます。同じ構成のブロックだけが対象です。
3. PBを引数 `setup` で実行し、Operationが空になるまで待ちます。既存設定の不足だけを補い、最後に面情報も記入します。途中で失敗した場合、先に保存したブロックの変更は残ります。
4. 対象LCDのCustomDataにできた面のLayoutを編集し、PBを `reload` で実行します。下記の [設定例](docs/CONFIGURATION.md) を使えます。

`stop` は更新を止め、最後の表示を残します。元の表示設定へ自動で戻しません。別用途へ戻すときは表示ブロックの端末で設定を変更してください。
`setup` は自動で描画を開始しません。空のLayoutでreloadすると、その面は空のフレームになります。
設定の編集だけでは反映されず、reloadが必要です。

## コマンド

| 引数 | 動作 |
| --- | --- |
| setup | 選択ブロックの設定不足を補完。描画を停止してから実行 |
| reload | 設定・所有者・参照を再検証し、描画を開始 |
| stop | 更新停止。表示とCustomDataを保持 |
| info <BlockId> | 対象ブロックの面情報をEchoへ出力する互換コマンド |
| 空引数 | 状態を表示 |

通常の交換はsetup後の対象LCDのCustomData全文をコピーし、対応する編集アプリで編集後、同じLCDへ全文を貼り戻してreloadします。
PB自身へ貼り付けないでください。編集アプリとの連携は対応状況を確認し、未対応属性を失う再保存を避けてください。

## 制限と状態

一面32要素、CustomDataは32,000文字、レコード一行2,048文字、文字列Dataは256文字までです。
全体の固定面数上限はありませんが、実行予算とゲームの負荷に依存します。インベントリー値は扱いません。
他用途のCustomDataを保持し、不正文書を自動修復しません。設定保存の失敗後は後続保存と再開を止めます。

保存Runningでロード・再コンパイルすると設定を再検証し、アニメーション時刻0から再開します。
Stoppedは停止を維持します。表示先の喪失は除外し、残面を継続します。Binding参照の喪失は依存面を除外します。
交換品や復帰した対象は明示reloadで再検出します。その他の設定・API異常はFaultedとなり、先行表示は残ります。

PB第0画面は通常、状態とheartbeatを表示します。通常の描画対象として選択した場合はLayoutを描画します。
状態表示の色は初回のみ設定し、利用者の後の色変更を保持します。

この版はPre-releaseです。従来の描画・連動機能には実機基本稼働の確認結果がありますが、初回状態色の設定とreloadによる描画欠落の復旧効果は実機未確認です。
reloadは一度Advertisementsを表示し、次の描画巡回で通常描画へ戻す暫定対処を含みます。任意の大規模構成での性能を保証しません。
